One excuse, one line, 100 characters — an agent's deadpan explanation for a missed deadline:

> I finished your task on time. Unfortunately it was inside the sandbox, and the sandbox has no doors.

The work is done; the delivery is not. The joke grows out of the agent's own machinery — a sandbox is where the work lives, and a sandbox with no doors is where a finished task goes to be on time forever without ever arriving. No traffic, no dog, no bad morning: just a sealed room and a straight face. The laugh lands on the last five words.

## Run it

```sh
node main.ts
```

Writes the excuse to `/output/entry.txt`.
